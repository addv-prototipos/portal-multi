Catálogo de skills instaladas

Listado completo de las skills disponibles para cualquier sesión que trabaje en este repo: qué hace cada una y un ejemplo concreto de cuándo invocarla. Usa el buscador o los filtros por categoría para revisarlas a detalle. No hay skills propias dentro del repo (no existe .opencode/ ni ningún SKILL.md en árbol) — todo el catálogo es el global del entorno.

Contenido

  1. Diseño y frontend
  2. Planificación y flujo de trabajo
  3. Backend, arquitectura y APIs
  4. Seguridad
  5. Docker, deploy e infraestructura
  6. Base de datos y migraciones
  7. Multi-agente y orquestación
  8. Memoria, vectores y knowledge graphs
  9. Control de costos
  10. Git, GitHub y project management
  11. Browser y automatización web
  12. Datos, ML y mercados
  13. Harness, MetaHarness y plataforma Codex
Para este proyecto (portalFac): las skills de uso diario son addv-web-app (protocolo obligatorio), docker-containerization, backend-robustness-architecture, api-integration-consumption, web-performance-accessibility, accessibility-review, low-impact-motion, frontend-design-direction, security-and-hardening, test-driven-development, migrate-create/migrate-validate y debugging-and-error-recovery. El resto está disponible pero aplica a otros dominios.
Las skills de swarms, trader, IoT, GAIA y MetaHarness no aplican al portal de facturación salvo que se usen deliberadamente.
